# 뉴스, 신작, 덕질 캘린더 설계

이 문서는 애니·만화·게임 뉴스, 신작 알림, 방영/연재/출시 일정, Live2D 덕질 브리핑을 설계할 때 참고한다. 커뮤니티 흐름은 [community.md](./community.md), 알림 정책은 [moderation-notifications.md](./moderation-notifications.md), DB 후보는 [data-model.md](./data-model.md)를 함께 본다.

## 1. 제품 방향

씹덕은 작품 백과사전이나 깊은 작품 DB를 직접 운영하는 서비스가 아니다. 목표는 사용자가 관심 있는 서브컬처 소식과 일정을 놓치지 않고, 그 흐름이 게시판/피드/댓글 활동으로 이어지는 덕질 커뮤니티 허브다.

- 뉴스는 운영자가 직접 작성·편집하는 자체 뉴스 서비스다.
- 신작 관리는 작품 DB가 아니라 관심작 알림 관리다.
- 캘린더는 메인 기능이 아니라 일정 확인과 알림 설정용 보조 화면이다.
- Live2D는 오늘 볼 것과 중요한 소식을 알려주는 짧은 덕질 비서로 쓴다.

## 2. 카테고리 분리 원칙

애니, 만화, 게임은 상위 입구에서는 함께 묶되 데이터와 화면 필터는 분리한다.

| 영역 | 주요 정보 | 권장 UX |
|------|-----------|---------|
| 애니 | 분기, 방영 요일, 방영 시간, 회차, OTT 공개, 휴방/연기 | 오늘 방영, 이번 주 방영, 내 관심작 알림 |
| 만화 | 연재일, 휴재, 단행본 발매, 정발, 웹연재 업데이트 | 오늘 연재/발매, 관심 작가/작품 알림 |
| 게임 | 출시, 업데이트, 점검, 이벤트, 패치노트, 사전예약 | 오늘 이벤트/점검, 출시 임박, 업데이트 알림 |

화면 입구 예시는 다음과 같다.

- `소식`: 전체, 애니, 만화, 게임 탭
- `신작/일정`: 애니 방영, 만화 연재/발매, 게임 출시/업데이트 탭
- Live2D 말풍선: 오늘 방영, 오늘 연재/발매, 오늘 게임 일정, 내 관심작 버튼

애니와 만화는 팬층이 겹치지만 일정의 문법이 다르다. 애니는 요일/시간/회차 중심이고, 만화는 연재/휴재/단행본 중심이므로 내부 모델과 알림 문구를 분리한다. 게임은 점검/이벤트/패치 흐름이 강하므로 별도 타입으로 다룬다.

## 3. 뉴스 기능

뉴스는 운영자가 직접 작성/편집하는 기사형 콘텐츠이며, 커뮤니티 활동으로 연결하는 기능이다.

### 뉴스 데이터 원칙

- 운영자가 직접 작성·편집한 기사 본문을 저장한다.
- 제목, 요약, 본문, 업로드 썸네일, 카테고리, 태그, 발행 시각, 등록/수정 시각을 저장한다.
- 중복 기사와 스팸성 보도자료를 운영자가 관리할 수 있어야 한다.
- 외부 자동 입력 파이프라인 없이 운영자가 직접 등록/수정하는 큐레이션을 우선한다.

### 뉴스 UX 요구

- 전체 뉴스와 애니/만화/게임 탭을 제공한다.
- 뉴스 카드에는 카테고리, 발행 시간, 관련 태그를 표시한다.
- 뉴스에서 바로 관련 게시판으로 이동할 수 있어야 한다.
- `토론글 쓰기`, `스크랩`, `관심 태그 알림` 액션을 제공한다.
- 같은 이슈의 중복 뉴스는 묶어서 보여줄 수 있어야 한다.
- 삭제되었거나 품질 기준에 맞지 않는 뉴스는 운영자 정책에 따라 숨길 수 있어야 한다.

## 4. 신작 관리

신작 관리는 작품 상세 DB가 아니라 일정 카드와 사용자 관심 등록을 중심으로 한다.

### 신작 데이터 원칙

- 작품/게임 정보는 얇은 참조 정보로만 저장한다.
- 외부 ID, 제목, 타입, 대표 이미지, 공식 링크, 태그, 기본 공개 상태 정도만 유지한다.
- 줄거리, 캐릭터, 제작진, 에피소드 상세처럼 유지보수가 큰 필드는 직접 소유하지 않는다.
- 외부 데이터가 바뀌거나 공식 일정이 변경될 수 있으므로 출처와 마지막 확인 시각을 남긴다.

### 신작 UX 요구

- 사용자는 신작을 관심 등록할 수 있다.
- 관심 등록한 신작은 알림 설정을 가질 수 있다.
- 애니 신작은 분기/요일/시간 중심으로 보여준다.
- 만화 신작은 연재 시작/단행본 발매/정발 중심으로 보여준다.
- 게임 신작은 출시일/사전예약/베타/업데이트 중심으로 보여준다.
- 신작 카드에는 `알림 받기`, `관련 채널`, `글쓰기`, `공식 링크` 액션을 둔다.

## 5. 덕질 캘린더

캘린더는 사용자가 직접 관리하는 복잡한 일정표가 아니라, 관심작과 공식/운영자 일정이 모이는 보조 화면이다.

### 일정 유형

- 애니 방영/OTT 공개
- 만화 연재/휴재/단행본 발매/정발
- 게임 출시/업데이트/점검/이벤트
- 커뮤니티 이벤트/운영 공지
- 사용자가 직접 추가한 개인 일정

### 캘린더 UX 요구

- 월간 보기와 오늘/이번 주 요약을 제공한다.
- 카테고리별 필터를 제공한다.
- 내 관심작만 보기와 전체 보기 전환을 제공한다.
- 일정 상세에서 알림 시간과 반복 여부를 설정할 수 있다.
- 일정 옆에 관련 게시판, 감상글 보기, 글쓰기 액션을 붙인다.
- `/calendar`는 URL 직접 접근 가능한 보조 화면으로 유지하되, GNB 노출 여부는 제품 단계에 맞춰 결정한다.

## 6. Live2D 덕질 브리핑

Live2D는 뉴스와 일정을 길게 설명하는 챗봇이 아니라, 짧은 말풍선과 버튼으로 오늘의 덕질 흐름을 보여주는 역할을 한다.

### 말풍선 버튼

- `오늘 방영`: 오늘 방영하는 관심 애니 목록
- `이번 주`: 이번 주 관심 일정 요약
- `내 관심작`: 관심 등록한 신작/작품/게임 목록
- `새 소식`: 관심 태그와 관련된 최근 뉴스

### 브리핑 응답

- 목록은 3~5개로 짧게 보여준다.
- 항목마다 시간, 제목, 타입, 주요 액션을 제공한다.
- 애니 항목은 `감상글 보기`, `글쓰기`, `관련 채널`로 이어진다.
- 만화 항목은 `연재/발매 확인`, `토론글 보기`, `관련 채널`로 이어진다.
- 게임 항목은 `패치노트/공식 링크`, `이벤트 보기`, `관련 채널`로 이어진다.

## 7. 알림 정책

뉴스와 신작 알림은 모든 소식을 밀어 넣는 방식이 아니라 사용자의 관심 설정을 따른다.

- 신작 공개 알림
- 방영/연재/출시 임박 알림
- 오늘 방영/오늘 연재/오늘 이벤트 알림
- 일정 변경, 휴방, 연기, 점검 변경 알림
- 관심 태그와 일치하는 주요 뉴스 알림

기본값은 과하지 않게 둔다. 예를 들어 신작 관심 등록 시 `당일 알림`만 기본 활성화하고, `30분 전`, `방영 후 감상 유도`, `변경 알림`은 사용자가 조정하게 한다.

## 8. 운영 정책

- 출처 없는 일정은 운영자 검토 상태로 둔다.
- 사용자 제보 일정은 바로 공개하지 않고 승인/반려 상태를 가진다.
- 스포일러 가능성이 있는 뉴스는 제목/썸네일 표시 정책을 둔다.
- 게임 점검/이벤트처럼 변경이 잦은 일정은 마지막 확인 시각을 보여준다.
- 뉴스와 일정은 커뮤니티 홍보글과 구분한다.

## 9. 완료 기준

- 애니/만화/게임 뉴스가 탭으로 분리되어 표시된다.
- 뉴스 카드에서 관련 게시판과 토론글 작성으로 이동할 수 있다.
- 신작은 깊은 작품 DB가 아니라 일정 카드와 관심 등록으로 관리된다.
- 사용자는 관심작 알림을 설정하고 알림 목록에서 받을 수 있다.
- Live2D 말풍선에 오늘 방영/이번 주/내 관심작/새 소식 버튼이 있다.
- 캘린더에서 내 관심작 일정만 필터링할 수 있다.
