# 오타쿠 커뮤니티 — 큰 축(Pillar) 후보 12선

> 이 문서는 동료 공유용 결정 전 자료다. 12개 중 어떤 후보가 사이트의 새 정체성·새 트래픽 축이 될 만한지 함께 판단하기 위해 정리했다. 모두 채택을 전제하지 않으며, 각 항목은 1~2분 안에 읽고 자기 평가를 표시할 수 있게 압축했다.

## 0. 읽기 전에

### 0.1 현재 사이트 맥락 (짧게)

- **프로젝트:** 씹덕 (가칭) — 애니·만화·게임 등 서브컬처를 다루는 한국어 덕질 커뮤니티
- **이미 진행 중인 것 (요약):**
  - 게시판·게시글·댓글(1단 대댓글)·추천/비추천·감정 리액션·개념글(단층)·신고/차단
  - 사용자 팔로우·게시판 팔로우·피드·크로스포스트
  - 프로필·고정닉/비고정닉/익명·**오시 등록(작품/캐릭터 5개)**·활동 배지 9종
  - 글로벌 Live2D 캐릭터·페이지별 대사·말풍선 알림·스티커
  - 애니/만화/게임 뉴스·신작 일정·`/calendar`·관심 등록
  - 이미지/영상 업로드·NSFW·아청법 위험 대응 검수 파이프라인
- **이 12개의 의미:** 위 기반에 **더해서** "새로운 사용자 행동·새로운 트래픽 축"을 만드는 큰 후보들이다. 게시판 안의 디테일 보강(태그·스포일러 마스킹·다층 개념글 등)은 별도 문서([otaku-experiments.md](./otaku-experiments.md))에 따로 정리되어 있어 여기서 다루지 않는다.

### 0.2 읽는 방법 권장

- 각 후보 끝에 본인 평가를 표시: `[좋음]` / `[고민]` / `[빼자]`
- "이건 더 큰 후보 같다" 또는 "여기에 없는 X 후보가 더 매력적이다" 같은 의견 환영
- 합의되면 1~2개를 골라 정식 도메인 문서로 깊이 파고, 브랜치 실험으로 진입한다

### 0.3 정체성 결정 무게 (선요약)

12개 중 사이트 정체성을 흔드는 무거운 결정은 **1·4·6·7**이다. 채택하면 "씹덕 = 무엇인가"의 한 줄 정의가 바뀐다. 나머지 8개는 메인 축은 그대로 두고 **새 영역을 추가**하는 결이라 결정이 더 가볍다.

## 1. 시청·독서·플레이 라이브러리 (한국형 작품 라이브러리)

- **가설:** 사용자별 "본 작품 / 보는 중 / 보고 싶은 / 드랍"을 점수·코멘트와 함께 트래킹하는 **개인 라이브러리**가 모든 활동의 중심이 된다.
- **새로 생기는 행동:** 분기 시청 일지, 친구 라이브러리 비교, "이 분기 너랑 나 4개 겹친다", 내 평점 그래프, 평점 분포로 본 연도별 베스트
- **현재 위치:** 한국에 비슷한 서비스가 사실상 없다. 오시·뉴스·캘린더가 자연스럽게 이리로 합쳐질 수 있는 **거대한 축**.
- **정체성 변화:** "씹덕 = 커뮤니티 + 라이브러리" 듀얼 정체성
- **위험·복잡도:** 작품 메타데이터 보유량이 운영 부담. 외부 무료 API는 정책 변경 위험이 있어 의존을 최소화하고, 운영자 직접 등록 + 자체 검색·자동화 보조로 채워간다. 평점 어뷰징·별점 인플레이션 정책 필요
- **평가:** `[ ]`

## 2. 워치파티 / 동시 시청

- **가설:** 신작 방영 시간에 사람들이 한 채팅방에 모여 본방을 함께 본다. 회차 단위 토론이 영상 종료와 동시에 자동으로 열린다.
- **새로 생기는 행동:** "오늘 22:30 진격 30화 같이 봐요", 본방 중 실시간 채팅, 종료 직후 감상 스레드 자동 개설, 늦게 본 사람용 "이번 화 토론 모음"
- **현재 위치:** 디스코드가 하던 역할인데, **작품 단위 한국어 모임을 사이트 안에 통합**하면 큰 차별화. 캘린더(신작 일정)와 자연스럽게 연결.
- **정체성 변화:** "씹덕 = 커뮤니티 + 실시간 본방 허브"
- **위험·복잡도:** 영상 자체 호스팅은 저작권 위험. **영상은 외부 시청(넷플릭스·라프텔·VOD) + 채팅만 동기화** 모델이 안전. 시차/스포일러 정책 필요
- **평가:** `[ ]`

## 3. VTuber·라이브 스트리머 통합 채널

- **가설:** 한국 오타쿠 트래픽의 큰 축은 V튜버다. **V 방송 알림·클립·팬 게시판이 사이트 안**에 있어야 한다.
- **새로 생기는 행동:** 최애 V 라이브 시작 푸시, 클립 모음 게시판, 슈퍼챗 인증, 콜라보 알림, V 입덕 가이드와 연결
- **현재 위치:** 뉴스·캘린더는 있지만 V 특화 흐름이 없다. V는 "오시"이자 "라이브 이벤트"라 별도 모델이 효율적.
- **정체성 변화:** 메인 축은 유지하되 **V 팬덤 트래픽 세그먼트**를 새로 흡수
- **위험·복잡도:** V 본인 인증, 가짜 클립·악성 클리퍼 단속, 외부 플랫폼(트위치·유튜브·치지직) API 의존
- **평가:** `[ ]`

## 4. 창작자 트랙 (Pixiv 한국판 미니)

- **가설:** 일러스트·소설·만화 **작품 자체**를 올리는 별도 트랙은 게시판 글과 다른 UX가 필요하다. 작품 페이지·시리즈·후원·코미션 안내가 한 묶음이 된다.
- **새로 생기는 행동:** 창작자 프로필, 작품 갤러리, "이 작가 시리즈 처음부터", 코미션 의뢰 문의, 후원/팬클럽
- **현재 위치:** 한국에 픽시브 대체재가 비어있다. 2차 창작 게시판으로는 부족한 **창작자 전용 트랙**.
- **정체성 변화:** "씹덕 = 커뮤니티 + 창작 플랫폼" 듀얼 정체성
- **위험·복잡도:** AI 생성물 표시 정책, 펌금·저작권, NSFW 처리(메인 트랙이면 검수 비용↑), 후원 들어가면 결제 PG 필요
- **평가:** `[ ]`

## 5. 굿즈·소장 컬렉션 DB + 위시리스트

- **가설:** 거래 없이도 "내가 가진 굿즈·BD·단행본·동인지·피규어"를 기록하고 자랑·비교하는 행동 자체가 큰 가치다.
- **새로 생기는 행동:** 굿즈 인증, 위시리스트 공유, 친구 컬렉션 보기, "이 작품 굿즈 다 모은 사람" 배지, 발매 알림과 연동
- **현재 위치:** 캘린더의 굿즈 발매 일정(별도 보강 후보)과 묶이지만, **컬렉션 자체는 별개 큰 축**.
- **정체성 변화:** 메인은 유지하되 **수집형 사용자**를 새 세그먼트로 끌어들임
- **위험·복잡도:** 굿즈 메타데이터 확보. 거래까지 가면 사기·미성년자 거래 위험 — **거래 없는 수집 트래커만** 먼저 안전
- **평가:** `[ ]`

## 6. 취향 매칭 / 친구·동행 추천

- **가설:** "당신과 오시 4개 겹치고 분기 시청작 6개 겹치는 사람" 매칭은 외로운 오타쿠가 사이트에 머무는 핵심 동력이 된다.
- **새로 생기는 행동:** 취향 일치도 기반 친구 추천, 같이 코미케 갈 사람 찾기, 같은 V 보는 사람 그룹 채팅, "이 작품 본 친구" 추천
- **현재 위치:** 오시 등록은 있지만 매칭 알고리즘이 없다. **사이트가 적극적으로 사람을 연결**하는 결로 가는 큰 결정.
- **정체성 변화:** "씹덕 = 커뮤니티 + 취향 매칭" 듀얼 정체성
- **위험·복잡도:** 그루밍·사칭·오프라인 동행 사고. **연령 확인·신뢰도·신고 정책 필수**. DM 정책과 함께 묶임
- **평가:** `[ ]`

## 7. 캐릭터 페르소나 챗을 메인으로 끌어올릴지

- **새로 생기는 행동:** 최애 캐릭터·V·오리지널 페르소나와 채팅, 사용자 제작 페르소나 공유·랭킹, 페르소나에서 시작되는 커뮤니티

- **정체성 변화:** "씹덕 = 커뮤니티 + 캐릭터 AI" 듀얼 정체성

## 8. 입덕 가이드 / 시청 순서 / 사용자 백과

- **가설:** "이 작품 입덕하려면 뭐부터 보지?", "프리큐어 시리즈 시청 순서", "이 V 입문 클립 베스트" 같은 가이드 콘텐츠는 **신규 유저 온보딩의 결정적 자산**이다.
- **새로 생기는 행동:** 사용자 작성 가이드 + 운영자 큐레이션, "입덕 성공" 좋아요, 가이드 시리즈 글, 외부 검색 유입
- **현재 위치:** 뉴스·캘린더와 결이 다른 **위키/큐레이션 축**. 위키처럼 운영하면 영구 자산이 된다.
- **정체성 변화:** 메인 유지 + **사이트가 미디어/지식 자산을 가짐**
- **위험·복잡도:** 스포일러 처리, 가이드 품질 관리, 위키 편집 권한 정책
- **평가:** `[ ]`

## 9. 실시간 활동 상태 — "지금 보는 중"

- **가설:** 디스코드 RPC처럼 "현재 ~ 시청 중 / ~ 플레이 중 / ~ 읽는 중"이 표시되면 라이브러리(1)·매칭(6)·워치파티(2)가 살아 움직인다.
- **새로 생기는 행동:** 친구 목록에서 누가 지금 무엇을 보는지 즉시 보임, "같이 봐도 돼?" 즉석 워치파티 호출, "지금 같은 작품 보는 사람" 라운지
- **현재 위치:** 단독으로는 작은 기능이지만 **라이브러리·매칭·워치파티의 접착제**라서 같이 갈 때 정서를 크게 바꿈
- **정체성 변화:** 메인은 유지하되 사이트 전체 정서를 "조용한 게시판"에서 "북적이는 라운지"로 이동
- **위험·복잡도:** 프라이버시(반드시 켜기 옵션·NSFW 숨김), 1·2·6 중 하나라도 같이 가지 않으면 별 가치 없음
- **평가:** `[ ]`

## 10. 시즌 패스 / 데일리 미션 / 분기 챌린지

- **가설:** 배지(누적 정적)만으로는 약하다. **분기마다 갱신되는 시즌 패스**(출석·시청·글·태그·매칭 활동으로 단계 진행)가 리텐션 핵심이 된다.
- **새로 생기는 행동:** 매일 들어올 이유, 분기 한정 호칭·스티커·캐릭터 의상 보상, "시즌 풀완료" 명예, 분기 라인업과 연동
- **현재 위치:** 정적 배지에 동적 **시즌제 게임화 축**을 추가
- **정체성 변화:** 메인 유지 + 리텐션 동력 강화
- **위험·복잡도:** 어뷰징(매크로·도배), 도파민 과부하 — 빈도·상한 조절 필요. 보상 디자인 비용
- **평가:** `[ ]`

## 11. 자동 트렌드 보고서 / "씹덕 위클리"

- **가설:** 매주 "이번 주 화제 작품 / 떡상 캐릭터 / 명대사 / 신작 1화 반응 요약 / V 핫클립"이 발행되면 **사이트 자체가 미디어 정체성**을 가진다.
- **새로 생기는 행동:** 위클리를 트위터·디스코드에 공유, 백넘버 아카이브, "이 주의 캐릭터" 자동 큐레이션, 외부 유입 채널화
- **현재 위치:** 게시판·뉴스가 인풋이라면 위클리는 아웃풋. **AI 자동 요약 + 운영자 편집** 결합 모델.
- **정체성 변화:** 메인 유지 + **사이트가 콘텐츠 발행 매체로도 동작**
- **위험·복잡도:** AI 요약 정확도, 작품 편향, 매주 발행 운영 부담
- **평가:** `[ ]`

## 12. 다국어 / 해외 팬 연결 허브

- **가설:** 일본 트위터·픽시브·해외 레딧 인기 콘텐츠를 자동 번역으로 큐레이션하고, 우리 글에도 영어/일본어 번역 옵션을 제공하면 **새로운 사용자 세그먼트**가 열린다.
- **새로 생기는 행동:** 해외 인기 팬아트 유입, 일본 공식 트윗 한국어 자막, 영어/일본어 댓글 교환, 해외 팬과 같은 작품 토론
