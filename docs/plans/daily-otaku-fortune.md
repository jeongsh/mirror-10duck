# 오늘의 덕질운 기획서

## 1. 결론

`오늘의 덕질운`은 랜덤 가챠가 아니라, 사용자의 생년월일과 간단한 오늘의 상태를 바탕으로 **실제 운세처럼 느껴지는 결과**를 제공하고, 그 위에 오타쿠식 해석을 얹는 독립형 바이럴 기능이다.

라우트 후보:

- `/play/fortune`

한 줄 설명:

> 생년월일과 별자리로 오늘의 진짜 운세를 보고, 덕질운까지 같이 점쳐준다.

핵심 방향:

- 돈/재화/확률형 아이템 느낌을 배제한다.
- 랜덤 드립보다 "내 정보 기반 운세"처럼 느껴지게 한다.
- Live2D 캐릭터는 점성술사/운세 안내자 역할을 한다.
- 결과는 일반 운세와 덕질 운세가 함께 나오는 카드로 공유한다.

## 2. 제품 목적

이 기능의 목적은 세 가지다.

- 매일 다시 들어올 이유를 만든다.
- Live2D 캐릭터를 장식이 아니라 진행자로 활용한다.
- 일반 운세의 몰입감과 오타쿠식 문구의 공유성을 결합한다.

단순 `오늘의 랜덤 카드`보다 개인화 체감이 강해야 한다. 사용자는 "아무거나 뽑았다"가 아니라 "오늘 내 운세를 봤다"고 느껴야 한다.

## 3. 사용자 흐름

1. `/play/fortune` 진입
2. Live2D 캐릭터가 오늘의 운세 안내
3. 생년월일 입력
4. 태어난 시간 선택 또는 `모름`
5. 별자리 자동 계산
6. 오늘 가장 신경 쓰이는 영역 선택
7. 오늘 피하고 싶은 것 선택
8. Live2D가 운세 해석 연출
9. 일반 운세 + 덕질 운세 결과 표시
10. 운세 부적 카드 저장/공유

## 4. 입력 정보

입력은 너무 많으면 이탈이 커진다. 필수 4개, 선택 2개 정도로 제한한다.

### 필수 입력

| 항목 | 설명 |
|------|------|
| 생년월일 | 별자리/기초 운세 계산에 사용 |
| 태어난 시간 | 선택지 제공, `모름` 허용 |
| 오늘 가장 신경 쓰이는 것 | 운세 문장과 강조 영역 보정 |
| 오늘 피하고 싶은 것 | 금지 행동/주의 문구 보정 |

### 선택 입력

| 항목 | 설명 |
|------|------|
| 닉네임 | 결과 카드에 표시 |
| 최애 장르 | 덕질운 문장 보정 |

### 오늘 가장 신경 쓰이는 것 선택지

- 인간관계
- 돈/소비
- 공부/일
- 건강/멘탈
- 덕질/취미

### 오늘 피하고 싶은 것 선택지

- 지출
- 스포일러
- 실수
- 감정 소모
- 미루기

### 태어난 시간 선택지

- 새벽
- 아침
- 낮
- 저녁
- 밤
- 모름

`모름`을 허용해야 한다. 태어난 시간을 모르는 사용자가 이탈하지 않게 한다.

## 5. 결과 구성

결과는 일반 운세와 오타쿠 운세를 함께 제공한다.

### 기본 결과 항목

- 오늘의 총운
- 금전운
- 인간관계운
- 멘탈운
- 덕질운
- 최애운
- 지갑방어력
- 스포회피력
- 오늘의 금지 행동
- 오늘의 행운 행동
- Live2D 캐릭터의 한마디

### 결과 예시

```text
오늘의 덕질운

SR: 떡밥 폭풍주의보

전체운
작은 선택이 의외로 좋은 흐름을 만듭니다.
다만 충동적으로 결정하면 오후에 후회할 수 있습니다.

금전운: 주의
사소한 결제가 쌓이기 쉬운 날입니다.
굿즈샵은 구경만 하세요.

덕질운: 높음
예상치 못한 떡밥이나 좋은 추천작을 만날 수 있습니다.

오늘의 금지 행동
새벽에 결제 버튼 누르기

오늘의 행운 행동
오전에 할 일 하나 끝내고 덕질하기
```

## 6. 운세 등급

등급은 확률형 보상처럼 보이면 안 된다. 결과 분위기와 공유용 라벨로만 사용한다.

등급 후보:

- `N`: 무난한 덕질일
- `R`: 작은 떡밥 감지
- `SR`: 덕질 기운 상승
- `SSR`: 최애운 강한 날
- `UR`: 공식보다 진심인 날
- `SECRET`: 우주가 최애 편

등급은 실제 가치 우열이 아니라 결과 카드의 분위기다.

## 7. 별자리/생년 기반 처리

### 별자리 계산

생년월일에서 별자리를 자동 계산한다.

별자리 결과는 운세 문장의 기본 톤과 강조 영역에 사용한다.

예:

- 불 계열: 행동, 본방, 추진력
- 물 계열: 감정, 최애운, 멘탈
- 바람 계열: 정보, 떡밥, 커뮤니케이션
- 흙 계열: 지갑방어력, 루틴, 안정

### 생년월일 처리

생년월일은 운세 계산에만 사용한다.

기본 정책:

- 비로그인 사용 가능
- 저장하지 않음이 기본값
- 로그인 유저도 저장은 선택
- 저장 시 명확한 안내 표시

안내 문구:

```text
입력한 생년월일은 운세 계산에만 사용되며, 기본적으로 저장하지 않습니다.
```

## 8. AI/API 사용 방향

AI를 쓰는 것은 가능하지만, 운세 전체를 AI에게 자유 생성으로 맡기지 않는다.

추천 구조:

```text
별자리/생년 기반 룰
  + 오늘의 관심사/회피 항목 보정
  + 운세 수치/등급 계산
  + 저렴한 AI로 한국어 문장화
  + 실패 시 템플릿 fallback
```

### AI가 담당하는 것

- 마지막 해석 문장
- Live2D 캐릭터 말투의 한마디
- 일반 운세와 덕질 운세를 자연스럽게 연결하는 문장

### AI가 담당하지 않는 것

- 등급 결정
- 수치 결정
- 금지 행동 결정
- 개인정보 저장 판단
- 민감한 조언

### API 사용 가능성

외부 운세 API가 있다면 사용할 수 있지만, 품질과 한국어 톤이 불안정할 수 있다. 따라서 API 의존 구조로 만들지 않는다.

우선순위:

1. 자체 룰 기반 결과 생성
2. AI 문장화
3. 외부 운세 API는 선택적 보조

## 9. Live2D 활용

Live2D는 단순 배경 장식이 아니라 운세 진행자다.

### 역할

- 질문 안내
- 입력 단계 전환
- 별자리 계산 중 연출
- 운세 해석 중 말풍선
- 결과 핵심 한 줄 전달

### 연출 매핑

| 상황 | Live2D 반응 |
|------|-------------|
| 시작 | greet / idle |
| 생년월일 입력 안내 | thinking |
| 별자리 계산 중 | special |
| 좋은 운세 | happy / celebrate |
| 주의 운세 | worried / surprised |
| 결과 공개 | 말풍선 + 카드 등장 |

### 말풍선 예시

```text
오늘은 지갑 방어력이 조금 약해 보여요.
굿즈샵은 들어가도 결제 버튼은 조심하세요.
```

```text
오늘은 떡밥운이 강해요.
공식이 조용하면 오히려 더 의심해야 할지도 몰라요.
```

## 11. 공유 카드

결과 이미지는 부적/별점 카드처럼 만든다.

필수 포함:

- `10duck 오늘의 덕질운`
- 날짜
- 닉네임 또는 `오늘의 나`
- 운세 등급
- 총평 한 줄
- 덕질운/최애운/지갑방어력/스포회피력
- 오늘의 금지 행동
- 오늘의 행운 행동
- 서비스 URL

예시:

```text
10duck 오늘의 덕질운
2026.05.30

SSR: 최애운 강한 날

최애운 88
덕질운 91
지갑방어력 24
스포회피력 67

금지 행동
공식 트윗 새로고침 30회 이상

행운 행동
본방 전에 할 일 하나 끝내기
```

## 12. 제한 정책

운세는 재생성보다 "오늘의 결과" 느낌이 중요하다.

권장:

- IP 기준 하루 1회 기본 운세
- 로그인 유저도 하루 1회 기본
- 공유하면 재점 1회 허용
- 하루 최대 2회
- 자정 리셋

문구:

```text
오늘의 운세는 이미 확인했어요.
결과를 공유하면 한 번 더 점쳐볼 수 있습니다.
공유하지 않아도 내일 다시 볼 수 있어요.
```

## 13. 저장 정책

기본:

- 비로그인 운세 결과는 서버 저장하지 않는다.
- 브라우저 localStorage에 당일 결과만 임시 저장할 수 있다.
- 로그인 유저도 생년월일 저장은 선택이다.

선택 저장:

- 생년월일 자동 입력
- 최근 운세 기록
- 공유 링크 유지

저장 시 명확히 표시한다.

```text
다음 운세에서 자동 입력하려면 생년월일 저장을 켜세요.
언제든 설정에서 삭제할 수 있습니다.
```

## 14. 안전/주의 사항

운세는 오락 콘텐츠임을 명확히 한다.

필수 원칙:

- 건강, 재정, 법률, 심리 문제에 단정적 조언을 하지 않는다.
- 불안감을 과하게 자극하지 않는다.
- 결제/소비를 부추기지 않는다.
- "나쁜 운세"도 유머와 주의 문구로 완화한다.
- 개인정보 저장 여부를 명확히 안내한다.

고지 문구:

```text
이 운세는 오락용 콘텐츠입니다. 중요한 결정은 운세가 아니라 실제 상황을 기준으로 판단해 주세요.
```

## 15. 구현 단계

### 1단계: 룰 기반 운세 MVP

- `/play/fortune` 라우트
- 생년월일/관심사/회피 항목 입력
- 별자리 계산
- 룰 기반 운세 결과 생성
- Live2D 말풍선 안내
- 결과 카드 표시

### 2단계: 공유 카드

- 운세 카드 이미지 캡처
- 저장/공유 버튼
- 당일 결과 localStorage 유지
- 하루 1회 제한

### 3단계: AI 문장화

- 룰 기반 결과를 입력으로 AI 문장 생성
- 실패 시 템플릿 fallback
- 말투 안정화
- 비용 제한

### 4단계: 로그인 확장

- 생년월일 저장 선택
- 운세 기록 저장 선택
- 공유 링크 저장
- 재점 제한 관리

## 16. 완료 기준

- 비로그인 유저가 생년월일을 입력하고 오늘의 운세를 볼 수 있다.
- 별자리가 자동 계산된다.
- 결과에는 일반 운세와 덕질 운세가 함께 나온다.
- Live2D 캐릭터가 안내/해석/결과 한마디를 제공한다.
- 운세 결과 카드를 이미지로 저장할 수 있다.
- 생년월일 저장 여부가 명확히 안내된다.
- 하루 제한이 동작한다.

## 17. 추천 포지션

`오늘의 덕질운`은 폭발형 바이럴보다는 **일일 재방문형 바이럴**이다.

티어표/월드컵처럼 논쟁을 만드는 기능은 아니지만, Live2D 차별화와 매일 확인하는 루틴을 만들기 좋다.

따라서 개발 우선순위는 다음 기준으로 판단한다.

- Live2D를 서비스 전면에 더 세우고 싶다면 우선순위를 올린다.
- 순수 공유 폭발력을 원한다면 티어표/인기투표/월드컵이 먼저다.
- 매일 들어오는 가벼운 놀이가 필요하다면 `오늘의 덕질운`이 적합하다.
