# 기존 바이럴 기능 미니게임화 강화안

## 1. 결론

이미 개발된 바이럴 기능 3종은 단순 생성/테스트 화면에 머물면 공유성은 있어도 "오타쿠가 좋아하는 놀이감"으로는 약하다. 강화 방향은 예쁜 스킨 추가가 아니라 **결과를 얻는 과정 자체를 미니게임처럼 느끼게 하는 것**이다.

대상 기능:

- `/play/oshi-card`: 최애 프로필 카드
- `/play/otaku-type`: 오타쿠 성향 테스트
- `/play/oshi-analysis`: 최애 기반 취향분석

추천 강화 요약:

| 기능 | 미니게임 방향 | 핵심 연출 |
|------|---------------|----------|
| 최애 프로필 카드 | 카드팩/강화/레어도 | 카드팩 개봉, 레어도 공개, 최애력 강화 |
| 오타쿠 성향 테스트 | 비주얼노벨/루트/엔딩 | 루트 분기, 엔딩 CG, 칭호 획득 |
| 최애 기반 취향분석 | 연구소/탐정/속성 공명 | 분석 로그, 태그 공명, 최애 파티 판정 |

우선순위는 `최애 기반 취향분석` → `최애 프로필 카드` → `오타쿠 성향 테스트` 순서다.

## 2. 공통 디자인 원칙

### 2.1 결과보다 과정이 재미있어야 한다

바이럴 결과 이미지만 예뻐서는 부족하다. 사용자가 만드는 동안 짧은 보상과 피드백을 받아야 한다.

공통 패턴:

- 버튼 클릭 후 즉시 결과를 보여주지 않고 0.8~1.5초 연출을 둔다.
- 선택마다 짧은 오타쿠식 피드백을 준다.
- 결과는 "분석/판정/개봉/엔딩"처럼 의식을 치르는 느낌으로 보여준다.
- 공유 이미지는 결과의 마지막 컷처럼 구성한다.

### 2.2 점수 우열이 아니라 장난식 판정이어야 한다

레어도, 위험도, 공명 레벨은 실제 가치 평가가 아니라 유머 장치다.

피해야 할 것:

- 유저를 낮게 평가하는 문구
- 성적/연애 해석 과다
- 특정 성별/취향 비하
- 미성년자처럼 보이는 캐릭터와 부적절한 관계 암시
- 정신건강 병리화

좋은 톤:

- `공식보다 진심임`
- `작가가 굴릴수록 사랑하는 타입`
- `세계관 빈틈 수사 중`
- `하차 못하는 사람`
- `최애 사망 플래그 감지`

### 2.3 기능 간 연결을 만든다

각 기능은 독립 결과로 끝나지 않고 서로 연결한다.

- 최애 카드 결과 → 최애 기반 취향분석
- 성향 테스트 결과 → 최애 카드/티어표
- 최애 기반 취향분석 결과 → 최애 카드/티어표/월드컵

## 3. 최애 프로필 카드 강화안

### 3.1 현재 기능 성격

`최애 프로필 카드`는 사용자가 최애와 취향을 카드 이미지로 만드는 생성기다. 이미 이미지 저장/공유와 잘 맞으므로, 여기에 **카드팩 개봉, 레어도, 강화** 감성을 얹는다.

### 3.2 추천 방향: 최애 카드팩 개봉

카드 생성 버튼을 누르면 바로 완성 카드가 뜨는 대신, 짧은 카드팩 개봉 연출을 보여준다.

흐름:

1. 최애 정보 입력
2. `[카드 생성]` 클릭
3. 카드팩 봉투가 흔들림
4. 빛나는 카드 실루엣 등장
5. 레어도 공개
6. 최종 카드 공개

레어도 예시:

- `N`: 입덕 감지
- `R`: 공식 설정 확인자
- `SR`: 최애 과몰입러
- `SSR`: 인생 저당 잡힘
- `UR`: 공식보다 진심임
- `SECRET`: 이건 사랑이 아니라 신앙

주의:

- 레어도는 우열이 아니라 랜덤/장난식 판정이다.
- 낮은 레어도가 실망스럽지 않게 문구를 웃기게 만든다.

### 3.3 카드 스탯

카드에 일반 능력치 대신 오타쿠식 스탯을 넣는다.

스탯 후보:

- `최애력`
- `서사력`
- `눈물 버튼`
- `공식 피해량`
- `굿즈 위험도`
- `떡밥 분석력`
- `회차 반복력`
- `사망 플래그 내성`

예시:

```text
최애력 98
서사력 82
공식 피해량 91
굿즈 위험도 76
```

### 3.4 기술명/효과

TCG 카드처럼 기술명을 넣는다.

기술명 예시:

- `설정 과몰입`
- `회차 반복 시청`
- `굿즈 장바구니 폭주`
- `공식 떡밥 해석`
- `최애 보호 본능`
- `스포일러 회피`
- `장례식장 예약`
- `순애 화력 방출`

효과 문구 예시:

```text
공식이 떡밥을 1개 던질 때마다 해석글을 3개 생성한다.
```

### 3.5 카드 강화 연출

카드 생성 후 추가 버튼으로 `최애력 강화`를 제공한다.

흐름:

1. 카드 생성 완료
2. `[최애력 강화]`
3. 강화 재료 선택: 태그, 문구, 칭호
4. 카드 테두리/배경/홀로 효과가 강화
5. 강화 결과 문구 표시

강화 결과 예시:

- `강화 성공: 공식보다 진심 단계 도달`
- `대성공: SECRET 최애 신앙 카드`
- `폭주: 굿즈 위험도 초과`

실패 연출은 넣지 않는다. 실패는 공유 경험을 꺾는다.

### 3.6 결과 공유 강화

공유 이미지에는 다음 요소를 넣는다.

- 레어도
- 최애명
- 칭호
- 대표 스탯 3개
- 기술명 1~2개
- `10duck에서 내 최애 카드 뽑기`

### 3.7 구현 우선순위

1. 레어도/칭호 문구 테이블
2. 카드팩 개봉 모달
3. 카드 스탯 표시
4. 최애력 강화 버튼
5. 강화 후 공유 이미지 반영

## 4. 오타쿠 성향 테스트 강화안

### 4.1 현재 기능 성격

`오타쿠 성향 테스트`는 질문에 답하면 덕질 성향 유형을 보여주는 테스트다. 강화 방향은 일반 심리테스트가 아니라 **비주얼노벨 루트 분기와 엔딩 공개**다.

### 4.2 추천 방향: 오타쿠 루트 분기 테스트

질문지를 평범한 설문처럼 보여주지 않고, 선택에 따라 루트가 갈리는 느낌을 준다.

흐름:

1. `당신의 덕질 루트가 시작됩니다`
2. 질문마다 상황극 연출
3. 선택할 때마다 게이지/루트 힌트 변화
4. 마지막에 엔딩 CG처럼 결과 공개

결과명은 `유형`보다 `엔딩`으로 표현한다.

엔딩 예시:

- `TRUE END: 심연의 설정 분석가`
- `BAD END: 굿즈 결제 후회 없음`
- `HIDDEN END: 최애 사망 장례위원장`
- `ROUTE CLEAR: 순애 과몰입 루트`
- `SECRET ROUTE: 공식 떡밥 망령`

### 4.3 질문 UI 톤

질문은 상황극 문장으로 쓴다.

예시:

```text
최애가 3화 만에 수상한 플래그를 세웠다.

A. 아니야 공식이 그럴 리 없어
B. 이미 장례식장 예약함
C. 떡밥 분석글 4천 자 작성
D. 굿즈부터 삼
```

선택 후 피드백:

- `처연 내성이 상승했습니다`
- `공식 불신 수치 +12`
- `굿즈 충동 게이지가 흔들립니다`
- `세계관 분석 루트에 진입했습니다`
- `하차 불가능 상태가 되었습니다`

### 4.4 게이지/레이더

결과 화면에는 성향 레이더를 넣는다.

축 후보:

- `과몰입`
- `분석`
- `소비`
- `순애`
- `피폐`
- `밈력`
- `본방력`
- `굿즈력`

게이지 문구 예시:

```text
피폐 내성 89%
공식 불신 74%
굿즈 충동 63%
정상 하차력 12%
```

### 4.5 칭호 획득

테스트 결과와 별도로 칭호를 준다.

칭호 예시:

- `공식 불신자`
- `떡밥 망령`
- `최애 보호자`
- `하차 못하는 사람`
- `본방 사수병`
- `스포일러 사냥꾼`
- `순애 원리주의자`
- `피폐물 내성 보유자`

### 4.6 결과 연결

결과 화면 CTA:

- `최애 카드 만들기`
- `최애 기반 취향분석 하기`
- `티어표로 반박하기`
- `나와 같은 엔딩 보기`

### 4.7 공유 이미지

공유 이미지는 엔딩 카드처럼 구성한다.

예시:

```text
오타쿠 성향 테스트
TRUE END

심연의 설정 분석가

당신은 작품을 보는 것이 아니라
세계관의 빈틈을 수사합니다.

획득 칭호: 떡밥 망령
```

### 4.8 구현 우선순위

1. 결과를 엔딩 표현으로 리네이밍
2. 질문 선택 후 짧은 피드백 추가
3. 결과 레이더/칭호 추가
4. 엔딩 카드 공유 이미지
5. 루트 분기 연출 고도화

## 5. 최애 기반 취향분석 강화안

### 5.1 현재 기능 성격

`최애 기반 취향분석`은 사용자가 고른 최애 캐릭터들의 태그를 합산해 취향을 분석한다. 질문지 테스트와 다르게, "내가 실제로 좋아한 캐릭터 목록으로 들키는 느낌"이 핵심이다.

강화 방향은 **취향 분석 연구소, 탐정 수사, 속성 공명, RPG 파티 판정**이다.

### 5.2 추천 방향: 취향 분석 연구소

최애를 고르면 바로 결과를 보여주지 말고 분석 로그를 출력한다.

흐름:

1. 최애 5~10명 선택
2. `[취향 분석 시작]`
3. 분석 로그 출력
4. 속성 공명 감지
5. 최애 파티 판정
6. 결과 공개

분석 로그 예시:

```text
냉미남 태그 감지...
처연 서사 반복 출현...
천재캐 선호도 과다...
빌런인데 순애인 케이스 발견...
힐러 부재 확인...
결론: 위험한 천재에게 약함
```

### 5.3 속성 공명

선택한 캐릭터들의 태그가 겹치면 "공명"이 발생한다.

공명 예시:

- `냉미남 공명 Lv.3`
- `처연 서사 공명 Lv.4`
- `광기캐 위험 수치 초과`
- `최애 사망 플래그 감지`
- `세계관 핵심 태그 과밀`
- `순애 회로 활성화`

결과 화면 예시:

```text
최대 공명 속성
처연 42%
냉미남 31%
세계관 핵심 18%
```

### 5.4 최애 파티 판정

선택한 최애들을 RPG 파티처럼 해석한다.

판정 항목:

- `메인 딜러`
- `탱커`
- `힐러`
- `버퍼`
- `디버퍼`
- `위험 요소`
- `멘탈 안정성`

예시:

```text
메인 딜러: 세계관 파괴자
탱커: 멘탈 이미 박살남
힐러: 없음
버퍼: 순애캐
위험 요소: 빌런 2명 포함

당신의 최애 파티는 강하지만 안정성이 없습니다.
힐러 없이 피폐 서사만 4명입니다.
```

힐러 없음, 빌런 과다, 주인공 부재 같은 판정이 공유성 높은 농담이 된다.

### 5.5 취향 위험도 게이지

장난식 위험도 게이지를 둔다.

게이지 후보:

- `정상성`
- `피폐 내성`
- `공식 불신`
- `사망 플래그 감지력`
- `조연 집착`
- `빌런 보호 본능`
- `구원서사 집착`
- `세계관 심연도`

예시:

```text
피폐 내성 91%
조연 집착 76%
공식 불신 68%
정상성 12%
```

### 5.6 결과 칭호

결과명은 더 자극적이고 공유하기 좋게 만든다.

예시:

- `상처 많은 천재캐 수집가`
- `빌런을 구원하려다 망하는 타입`
- `주인공보다 조연 장례식에 진심인 사람`
- `공식이 굴릴수록 사랑하는 타입`
- `차가운 얼굴에 무너진 속내를 찾는 사람`
- `힐러 없이 피폐 파티만 짜는 사람`
- `세계관 핵심만 골라 고통받는 타입`

### 5.7 CTA

결과 화면 CTA:

- `이 파티로 티어표 만들기`
- `최종 보스급 최애 카드 만들기`
- `이 취향으로 월드컵 하기`
- `태그가 이상하면 수정 제안`
- `내 최애가 없으면 구조 요청`

### 5.8 공유 이미지

공유 이미지 구성:

- 결과 칭호
- 최대 공명 속성 Top 3
- 최애 파티 판정 한 줄
- 취향 위험도 게이지 3개
- 선택한 최애 목록
- `10duck에서 내 취향도 들켜보기`

예시:

```text
내 최애 10명으로 보는 취향 분석

힐러 없이 피폐 파티만 짜는 사람

최대 공명: 처연 Lv.4 / 냉미남 Lv.3 / 세계관 핵심 Lv.3
파티 판정: 강하지만 안정성이 없습니다
정상성 12% · 피폐 내성 91% · 조연 집착 76%
```

### 5.9 구현 우선순위

1. 분석 로그 연출
2. 속성 공명 계산/표시
3. 최애 파티 판정
4. 취향 위험도 게이지
5. 결과 공유 이미지 반영

## 6. 전체 우선순위

### 1순위. 최애 기반 취향분석

가장 먼저 손본다.

이유:

- 질문지 테스트와 차별화가 가장 쉽다.
- "내 취향 들킴" 감성이 강하다.
- 분석 로그와 속성 공명을 넣으면 미니게임성이 바로 생긴다.
- 캐릭터 태그 DB와 자연스럽게 연결된다.

### 2순위. 최애 프로필 카드

이유:

- 이미 이미지 공유용 기능이라 미니게임 연출이 바로 결과물에 반영된다.
- 카드팩 개봉/레어도/강화는 오타쿠와 게임 감성에 잘 맞는다.
- 개발 범위를 단계적으로 나누기 쉽다.

### 3순위. 오타쿠 성향 테스트

이유:

- 비주얼노벨 루트/엔딩으로 바꾸면 강해진다.
- 다만 질문지 구조와 결과 체계를 다시 다듬어야 해서 리디자인 범위가 상대적으로 크다.

## 8. 금지/주의 사항

- 실패/낮은 등급으로 유저 기분을 상하게 하지 않는다.
- 레어도나 위험도는 진짜 우열이 아니라 농담이어야 한다.
- 캐릭터와 유저의 관계를 과도하게 연애/성적 맥락으로 몰지 않는다.
- 미성년자처럼 보이는 캐릭터를 부적절한 문구와 연결하지 않는다.
- 결과 문구는 오타쿠식이되, 혐오/비하/정신질환 조롱으로 가지 않는다.
