# 과몰입 클리닉 애니 처방전 기획서

이 문서는 애니 추천 기능을 일반 장르 추천기가 아니라 **오타쿠 취향 진단형 추천 콘텐츠**로 만들기 위한 제품 기획서다. 핵심 컨셉은 `과몰입 클리닉 / 애니 처방전`이며, 사용자는 애니를 추천받는 것이 아니라 자신의 현재 상태와 취향을 진단받고 그에 맞는 작품을 처방받는 경험을 해야 한다.

## 1. 기능 한 줄 정의

`과몰입 클리닉`은 사용자의 현재 감정, 취향 반응, 지뢰 요소, 최근 감상 이력을 문진표처럼 해석해 기존 작품 태그 기반 애니 후보를 처방전 형식으로 추천하는 바이럴형 취향 진단 기능이다.

핵심 문구:

> 그냥 볼 애니를 찾으러 오셨겠지만, 대부분은 그보다 상태가 조금 더 심각합니다.

## 2. 핵심 차별점

### 일반 추천기와의 차이

| 항목 | 일반 애니 추천 | 과몰입 클리닉 |
|------|----------------|---------------|
| 입력 | 장르, 분위기, 평점 | 증상, 감정, 최애 반응, 지뢰, 최근 감상 |
| 출력 | 추천 작품 리스트 | 진단명, 처방전, 효능, 복용법, 부작용 |
| 근거 | 태그 매칭, 유사도 | 태그 매칭 + 취향 해석 + 회피 조건 |
| 말투 | 정보 제공형 | 차분한 의사 말투 + 오타쿠 위트 |
| 공유 | 작품 추천 결과 | 진단명과 처방 작품이 들어간 공유 카드 |
| 재시도 | 다시 추천 | 재처방: 약이 셈/약함/최애 성분 부족/지뢰 발생 |

### 제품 원칙

1. **재미가 입력 단계부터 시작되어야 한다.**
   - 문진표, 접수, 진료 과목, 알레르기 검사, 처방전 같은 병원 메타포를 사용한다.
   - 단, 실제 의료 서비스처럼 오해될 수 있는 표현은 피하고 엔터테인먼트용 취향 진단임을 명확히 한다.

2. **추천 정확도는 기존 태그 해석에서 나온다.**
   - 새 태그를 무리하게 만들지 않는다.
   - 기존 작품/캐릭터/관계성 태그를 추천용 표현으로 번역한다.
   - 좋아하는 요소보다 싫어하는 요소를 피하는 것을 강하게 반영한다.

3. **말맛은 기능의 핵심 품질이다.**
   - 차분한 병원/의사 말투 60%, 오타쿠 취향을 찌르는 위트 30%, 가벼운 독설 10%.
   - 사용자를 조롱하지 않고 "찔리지만 기분 나쁘지 않은" 정도로 쓴다.
   - `추천`보다 `처방`, `시청`보다 `복용`, `주의점`보다 `부작용/주의사항/금지약`을 우선 사용한다.

4. **결과는 공유하고 싶어야 한다.**
   - 진단명, 한 줄 요약, 취향 키워드, 처방 작품 3개, 과몰입 수치, 주의사항을 짧고 강하게 보여준다.
   - 공유 카드만 봐도 "나도 진료받고 싶다"는 진입 동기가 생겨야 한다.

## 3. 사용자 플로우

1. `/play/anime-clinic` 또는 바이럴 허브에서 `과몰입 클리닉` 진입
2. 접수 화면에서 컨셉과 CTA 확인
3. 진료 과목 선택
4. 문진표 6~8문항 작성
5. 지뢰 요소 알레르기 검사
6. 최근 재밌게 본 작품 최대 3개 입력 또는 선택
7. 최근 별로였던 작품 최대 3개 입력 또는 선택
8. 진단 중 로딩 화면
9. 진단 결과와 애니 처방전 표시
10. 재처방 버튼으로 방향 조정
11. 공유 카드 생성 및 저장

### 이탈 방지 원칙

- 전체 질문은 7개를 기본으로 하고, 최근 감상 입력은 선택으로 둔다.
- 검색 입력은 `작품을 몰라도 넘어가기`를 제공한다.
- 로딩은 실제 계산보다 길게 끌지 않고 0.8~1.5초의 짧은 연출로 처리한다.
- 결과까지 도달한 사용자는 재처방으로 같은 플로우를 다시 타지 않게 한다.

## 4. 화면별 상세 기획

### 4.1 접수 화면

목표:

- 사용자가 "평범한 애니 추천기가 아니다"라고 즉시 느끼게 한다.
- 병원 접수실 같지만 무겁지 않은 톤을 만든다.
- 결과 공유 기대감을 만든다.

구성:

- 헤더: `과몰입 클리닉`
- 서브 타이틀: `애니 처방전 발급소`
- 접수 문구
- CTA 1개: `진료 시작하기`
- 보조 CTA: `오늘은 가볍게 처방만 받기`
- 하단 안내: `이 진단은 엔터테인먼트용 취향 테스트입니다. 실제 의료 조언이 아닙니다.`

카피 버전:

1. `어서 오세요. 여기는 과몰입 클리닉입니다. 그냥 볼 애니를 찾으러 오셨겠지만, 대부분은 그보다 상태가 조금 더 심각합니다.`
2. `최근 작품을 켜도 심장이 예전만큼 뛰지 않나요? 문진표를 작성해 주세요. 취향 반응이 둔해진 원인을 확인하겠습니다.`
3. `오늘의 증상에 맞는 애니를 처방합니다. 단, 최애 발생과 후유증은 보장하지 않습니다.`
4. `보고 싶은 건 많은데 막상 누르면 식는 상태. 흔한 증상입니다. 접수부터 진행하겠습니다.`
5. `가벼운 힐링이 필요한지, 며칠 멍해질 작품이 필요한지 먼저 확인하겠습니다.`
6. `진료 전 안내: 이곳에서는 장르보다 증상을 먼저 봅니다.`
7. `추천받으러 왔다고 생각하셨겠지만, 지금 필요한 건 처방전일 수 있습니다.`
8. `취향은 숨길 수 있습니다. 다만 문진표는 대체로 솔직합니다.`
9. `최애 중독, 후유증 결핍, 배틀뽕 금단. 의심 증상이 있으면 접수해 주세요.`
10. `유명작이라는 이유만으로 처방하지 않습니다. 현재 상태에 맞는 약효를 확인합니다.`

### 4.2 진료 과목 선택

MVP 진료 과목은 5개로 제한한다.

| 과목 | 버튼명 | 한 줄 설명 | 추천 방향 | 기대 결과 |
|------|--------|------------|-----------|-----------|
| 멘탈 회복과 | `밥 먹고 웃는 애들 주세요` | 현실에 치인 당신에게 저자극 회복식을 처방합니다. | 일상, 코미디, 학원, 따뜻한 관계성, 부담 없는 작품 | 기분 전환, 안정감, 가벼운 재시청 욕구 |
| 후유증 내과 | `보고 나서 멍해지고 싶어요` | 다 본 뒤 천장을 바라보는 시간을 처방합니다. | 감정선, 여운, 구원서사, 비극성, 완성도 높은 결말 | 강한 몰입, 여운, 인생작 후보 |
| 배틀뽕 정형외과 | `가슴이 웅장해지는 장면이 부족해요` | OST가 깔리고 주인공이 일어서는 순간을 보충합니다. | 액션, 이능력, 각성, 라이벌, 작화 폭발, 카타르시스 | 즉각적 흥분, 명장면 회상, 클립 재탐색 |
| 최애중독 정신과 | `캐릭터 한 명에게 인생 저당 잡힌 적 있어요` | 작품보다 사람 하나에 먼저 감기는 증상을 확인합니다. | 캐릭터성, 처연캐, 천재캐, 빌런, 관계성, 구원서사 | 최애 발생, 관계성 탐색, 2차 검색 욕구 |
| 지뢰 회피과 | `싫은 것부터 빼고 싶어요` | 좋아하는 것을 찾기 전에 못 견디는 성분을 제거합니다. | 지뢰 필터링, 완결 여부, 서비스신, 고구마, 잔인함 회피 | 추천 실패 감소, 안전한 후보, 납득 가능한 제외 |

진료 과목별 설명 문구:

- 멘탈 회복과
  - `현실에 치인 당신에게 밥 먹고 웃는 애들이 필요합니다.`
  - `지금은 세계관보다 도시락, 비극보다 단체 하교가 필요합니다.`
  - `큰 사건 없이도 마음이 조금 나아지는 작품을 봅니다.`
  - `감정선 과다 복용을 잠시 중단하고 저자극 처방으로 전환합니다.`
  - `복잡한 떡밥보다 귀여운 대화가 더 잘 듣는 상태입니다.`

- 후유증 내과
  - `보고 나서 괜찮은 척하지만 계속 생각나는 작품을 처방합니다.`
  - `감정선 반응이 둔해진 환자에게 강한 여운을 투여합니다.`
  - `다 본 뒤 아무 말 없이 엔딩곡을 다시 틀 가능성이 있습니다.`
  - `행복해졌으면 좋겠는데 고통받는 장면을 계속 보는 분께 적합합니다.`
  - `가벼운 추천으로는 약효가 부족한 상태입니다.`

- 배틀뽕 정형외과
  - `가슴이 웅장해지는 장면 섭취량이 부족합니다.`
  - `필살기, 각성, 라이벌전, OST 반응성을 측정합니다.`
  - `주인공이 쓰러졌다가 다시 일어나는 순간에 약효가 나타납니다.`
  - `잔잔한 작품을 처방하면 오히려 증상이 악화될 수 있습니다.`
  - `작화 폭발과 카타르시스가 필요한 상태입니다.`

- 최애중독 정신과
  - `작품을 보러 갔다가 캐릭터에게 인생을 저당 잡힌 기록이 있습니다.`
  - `웃고 있지만 속은 너덜너덜한 인물에게 반응이 빠릅니다.`
  - `이번 처방에도 위험 인물이 포함될 수 있습니다.`
  - `본인은 서사가 좋다고 말하지만, 이미 프로필을 검색하고 있습니다.`
  - `치료보다는 안전한 감상이 우선입니다.`

- 지뢰 회피과
  - `좋아하는 것을 찾기 전에 싫어하는 성분을 제거합니다.`
  - `열린 결말, 과한 서비스신, 고구마 전개를 사전 검사합니다.`
  - `추천 실패의 대부분은 취향 부족이 아니라 지뢰 방치에서 발생합니다.`
  - `현재 상태에서 밟으면 회복이 늦어질 작품을 분리합니다.`
  - `안전한 처방이 먼저 필요한 분께 적합합니다.`

### 4.3 문진표 화면

UX 구성:

- 상단: `문진표 3 / 7`
- 질문 카드: 병원 문진표 스타일
- 선택지: 라디오 또는 체크박스
- 선택 후 즉시 다음으로 넘어가지 않고 `다음 문항` 버튼 제공
- 하단: `정확한 처방을 위해 솔직히 답변해 주세요. 취향은 이미 데이터가 알고 있습니다.`

### 4.4 진단 중 화면

구성:

- 진행 상태: `취향 반응 검사 중`
- 랜덤 로딩 문구 2~3개 순환
- 작은 태그 칩 애니메이션: `구원서사`, `작화폭발`, `열린 결말`, `지뢰 제거`

### 4.5 결과 페이지

상세 구조는 9장에서 정의한다. 결과 페이지는 정보 제공 화면이 아니라 처방전 문서처럼 보여야 한다.

## 5. 문진 질문 목록

MVP는 7문항으로 시작한다. 7번과 8번의 최근 감상 입력은 선택형 보조 데이터로 취급한다.

### 질문 1. 최근 애니를 볼 때 가장 자주 드는 증상은?

| 선택지 | 내부 성향 |
|--------|-----------|
| 재밌긴 한데 심장이 예전만큼 뛰지 않는다 | 강한 몰입 결핍, 후유증/카타르시스 필요 |
| 캐릭터가 안 꽂히면 1화도 버티기 어렵다 | 캐릭터성 중심, 최애 발생 의존 |
| 세계관이 얕으면 금방 식는다 | 설정/정치극/SF/판타지 세계관 중심 |
| 아무 생각 없이 웃고 싶다 | 저자극, 개그, 일상, 멘탈 회복 |
| 누가 내 멘탈을 정중하게 찢어줬으면 좋겠다 | 감정선, 비극성, 구원서사, 여운 |

### 질문 2. 오늘 처방받고 싶은 감정은 무엇인가요?

| 선택지 | 추천 방향 |
|--------|-----------|
| 따뜻하게 회복되고 싶다 | 일상, 힐링, 코미디, 관계 안정 |
| 울고 싶지만 울었다고 인정하긴 싫다 | 감정선, 성장, 절제된 눈물 |
| 가슴이 웅장해지고 싶다 | 액션, 이능력, 스포츠, 각성 |
| 뇌를 잠시 퇴근시키고 싶다 | 개그, 학원, 에피소드형, 가벼운 작품 |
| 다 보고 나서 천장만 바라보고 싶다 | 후유증, 열린 질문, 강한 결말 |

### 질문 3. 다음 중 당신이 가장 쉽게 무너지는 캐릭터는?

| 선택지 | 캐릭터 취향 |
|--------|-------------|
| 혼자 다 짊어지는 무뚝뚝한 강자 | 책임감, 고립, 처연, 강자 서사 |
| 웃고 있지만 속은 이미 너덜너덜한 캐릭터 | 내면 상처, 방어적 유머, 구원 욕구 |
| 재능은 미쳤는데 인성이 약간 불량한 천재 | 천재캐, 능글, 전략가, 문제적 매력 |
| 서사는 빌런인데 얼굴과 과거사가 설득하는 타입 | 빌런 서사, 사연, 도덕적 회색지대 |
| 처음엔 별생각 없었는데 어느 순간 최애가 되어 있는 타입 | 서서히 감기는 캐릭터, 케미, 성장형 호감 |

### 질문 4. 좋아하는 관계성은?

| 선택지 | 관계성 취향 |
|--------|-------------|
| 처음엔 티격태격하다가 결국 서로를 인정하는 라이벌 | 라이벌, 성장, 경쟁, 인정 |
| 스승과 제자처럼 서로를 성장시키는 관계 | 사제관계, 성장, 전승 |
| 말은 험하지만 결국 서로를 구원하는 관계 | 구원서사, 상처, 관계성 중독 |
| 피는 안 섞였지만 가족보다 가족 같은 관계 | 유사가족, 소속감, 보호 |
| 서로 이해하면 안 될 것 같은데 이상하게 얽히는 관계 | 금기성 케미, 빌런/히어로, 심리전 |

### 질문 5. 복용 전 알레르기 검사가 필요합니다. 못 견디는 요소를 골라주세요.

복수 선택 가능:

- 답답한 주인공
- 열린 결말
- 과한 서비스신
- 작화 기복
- 너무 느린 초반
- 설명만 많은 세계관
- 갑자기 분위기 하렘
- 너무 잔인한 장면
- 미완결
- 지나친 고구마 전개

추천 반영:

- 지뢰는 선호 태그보다 높은 가중치로 제외/감점한다.
- 완전히 제외할 수 없는 경우 `주의약`으로 표시한다.
- 지뢰와 일치하지만 추천 강도가 높은 작품은 `고위험 고효능`에 배치하고 이유를 설명한다.

### 질문 6. 원하는 작품 길이는?

| 선택지 | 후보 조정 |
|--------|-----------|
| 12화 정도로 가볍게 | 1쿨 완결/짧은 시즌 우선, 장편 감점 |
| 24화 정도는 가능 | 2쿨 작품 허용, 장편은 후순위 |

| 상관없음 | 길이 가중치 최소화 |

### 질문 7. 최근 재밌게 본 작품을 입력해주세요.

입력 방식:

- 검색으로 작품 선택
- 직접 입력 가능
- 최대 3개
- 비워도 진행 가능

활용:

- 선택 작품의 기존 태그를 가산점으로 사용한다.
- 공통 태그가 반복되면 취향 성향으로 승격한다.
- 예: `이능력 + 배틀 + 동료서사 + 각성` 반복 시 `배틀뽕`, `동료서사`, `성장서사` 성향을 강화한다.

### 질문 8. 최근 별로였던 작품을 입력해주세요.

입력 방식:

- 직접 입력 가능
- 최대 3개
- 비워도 진행 가능

활용:

- 해당 작품과 비슷한 작품을 전부 제외하지 않는다.
- 별로였던 작품의 태그 중 사용자가 고른 지뢰와 겹치는 태그만 강하게 감점한다.
- 별로였던 이유가 불명확하면 결과에서 `주의약` 설명에 반영한다.

추가 문진 후보:

7. `장편 입덕 시 가장 큰 장벽은 무엇인가요?`
8. `로맨스가 들어오면 약효가 올라가나요, 떨어지나요?`

10. `다 본 뒤 커뮤니티 해석글을 찾아보는 편인가요?`

## 6. 기존 태그를 추천용으로 해석하는 방법

### 해석 구조

기존 태그는 내부 추천 계산에 사용하고, 결과 페이지에는 아래 3단계로 번역해 보여준다.

1. **태그 묶음**: `액션 + 이능력 + 성장`
2. **추천 해석**: `배틀뽕, 각성 연출, 카타르시스`
3. **처방전 표현**: `최근 가슴이 웅장해지는 장면 섭취량이 부족합니다.`

### 태그 번역 예시

| 기존 태그 | 추천 해석 | 처방전 표현 |
|-----------|-----------|-------------|
| 액션 / 이능력 / 성장 | 배틀뽕, 각성 연출, 카타르시스 | `최근 가슴이 웅장해지는 장면 섭취량이 부족합니다.` |
| 일상 / 코미디 / 학원 | 멘탈 회복, 저자극, 뇌 퇴근용 | `현실에 치인 당신에게 밥 먹고 웃는 애들이 필요합니다.` |
| 구원서사 / 유사가족 / 희생 | 관계성 중독, 감정선 자극, 후유증 | `행복했으면 좋겠다고 말하면서 고통받는 장면을 계속 보고 있습니다.` |
| 판타지 / 정치극 / 디스토피아 | 설정 과몰입, 권력 구조, 세계관 해부 | `캐릭터 이름보다 조직도를 먼저 외우는 상태입니다.` |
| SF / 미스터리 / 추리 | 떡밥 추적, 가설 세우기, 두뇌 자극 | `작품을 보는 게 아니라 단서를 복용하고 있습니다.` |
| 라이벌 / 스포츠 / 성장 | 경쟁 서사, 인정 욕구, 팀 카타르시스 | `서로 으르렁대다가 인정하는 순간에 반응이 큽니다.` |
| 로맨스 / 학원 / 코미디 | 설렘 보충, 관계 진전, 가벼운 도파민 | `고백보다 삽질을 더 오래 지켜볼 준비가 되어 있습니다.` |
| 아이돌 / 성장 / 유사가족 | 응원 중독, 무대 카타르시스, 팀 서사 | `무대보다 대기실 관계성에서 약효가 올라갈 수 있습니다.` |
| 잔인함 / 디스토피아 / 정치극 | 고위험 고효능, 생존 압박, 멘탈 소모 | `약효는 강하지만 복용 후 회복 시간이 필요합니다.` |
| 열린 결말 / 느린 전개 / 미스터리 | 해석 여지, 장기 여운, 커뮤니티 토론 | `정답보다 해석글을 더 오래 보게 될 수 있습니다.` |
| 하렘 / 서비스신 / 코미디 | 호불호 성분, 가벼운 자극, 캐릭터 소비 | `이번 처방에서는 불필요한 부작용 여부를 먼저 확인합니다.` |
| 미완결 / 판타지 / 성장 | 장기 관찰, 원작 추적, 입덕 비용 | `약효가 끝나기 전에 다음 시즌을 기다리게 될 수 있습니다.` |

## 7. 진단명 목록

진단명은 결과 공유의 핵심이다. 내부적으로는 사용자 응답, 태그 점수, 지뢰, 최근 감상 기반으로 1개 대표 진단명과 1~2개 보조 키워드를 고른다.

| 진단명 | 조건 | 진단 소견 예시 | 추천 방향 | 공유 카드 한 줄 요약 |
|--------|------|----------------|-----------|----------------------|
| 후유증 결핍 증후군 | 여운, 감정선, 강한 결말 반응 높음 | `무난한 작품만 복용해 감정선 반응이 둔해진 상태입니다.` | 후유증, 비극성, 완성도 높은 결말 | `가볍게 보려다 며칠 생각나는 작품이 필요한 상태` |
| 처연캐 재발성 감염 | 상처 많은 강자, 구원서사, 내면 상처 선호 | `혼자 버티는 캐릭터에게 반복적으로 반응합니다.` | 처연캐, 구원서사, 관계성 | `행복했으면 좋겠다고 말하면서 고통받는 장면을 계속 봅니다` |
| 배틀뽕 금단증상 | 액션, 이능력, 각성, 작화 폭발 선호 | `OST와 각성 연출에 대한 반응성이 높게 나타납니다.` | 액션, 배틀, 성장, 라이벌 | `가슴이 웅장해지는 장면 섭취량이 부족합니다` |
| 세계관 분석 과다증 | 세계관, 정치극, SF, 디스토피아 선호 | `캐릭터보다 조직도와 권력 구조가 먼저 보입니다.` | 설정, 떡밥, 정치극, SF | `작품을 보는 게 아니라 설정집을 뜯어먹는 중` |
| 최애 의존성 과몰입 | 캐릭터성, 관계성, 최애 발생률 높음 | `작품 전체보다 캐릭터 한 명에게 먼저 감기는 경향이 있습니다.` | 캐릭터 중심, 관계성, 처연/천재/빌런 | `추천작보다 위험 인물을 먼저 찾는 상태` |
| 현실도피성 개그 결핍 | 일상, 코미디, 저자극 욕구 높음 | `복잡한 세계관보다 즉각적인 웃음과 케미가 필요합니다.` | 일상, 학원, 코미디 | `뇌를 잠시 퇴근시킬 처방이 필요합니다` |
| 유사가족 영양실조 | 유사가족, 보호, 소속감 반응 높음 | `피보다 진한 관계와 같이 밥 먹는 장면에 약합니다.` | 유사가족, 따뜻한 관계성 | `가족보다 가족 같은 애들이 필요한 상태` |
| 라이벌 인정중독 | 라이벌, 성장, 경쟁, 스포츠 반응 높음 | `싸우다가 인정하는 순간에 심박이 상승합니다.` | 스포츠, 배틀, 성장 | `서로 물어뜯다가 서로를 키우는 관계에 약합니다` |
| 천재캐 위험 선호 | 천재, 전략가, 문제적 인물 선호 | `재능은 뛰어나고 인성은 애매한 인물에게 집중합니다.` | 천재캐, 심리전, 미스터리 | `인성보다 능력치에 먼저 설득되는 상태` |
| 빌런서사 면역저하 | 빌런, 과거사, 회색지대 선호 | `나쁜 줄 알면서도 사연을 들으면 흔들립니다.` | 빌런 서사, 심리전, 어두운 작품 | `과거사 한 컷에 판단력이 약해집니다` |
| 저자극 회복 필요형 | 멘탈 회복, 일상, 코미디 선호 | `현재는 강한 감정선보다 안정적인 웃음이 더 적합합니다.` | 일상, 힐링, 학원 | `큰 사건 없이 웃는 애들이 필요한 상태` |
| 떡밥 추적 과각성 | 추리, 미스터리, 열린 결말 선호 | `대사 하나를 그냥 넘기지 못하는 상태입니다.` | 미스터리, 추리, SF | `엔딩 후에도 혼자 해석을 계속합니다` |
| 고위험 고효능 선호증 | 잔인함/비극성 허용, 강한 작품 선호 | `호불호가 큰 작품일수록 인생작 가능성이 커집니다.` | 어두운 명작, 강한 후유증 | `부작용을 알면서도 약효가 센 쪽을 고릅니다` |
| 완결 안정제 의존형 | 미완결 지뢰, 완결작 선호 | `기다림보다 깔끔한 결말에서 만족도가 높습니다.` | 완결작, 결말 완성도 | `다음 시즌 소식에 멘탈을 맡기지 않습니다` |

| 입덕 초기 안전처방형 | 지뢰 많음, 짧은 작품 선호 | `현재는 강한 작품보다 실패 확률이 낮은 처방이 필요합니다.` | 짧은 완결, 저위험 작품 | `좋아하는 것보다 싫은 것을 피해야 하는 상태` |

| 디스토피아 내성 보유 | 디스토피아, 정치극, 잔인함 허용 | `망한 세계를 보면서 인간성을 확인하고 싶어 합니다.` | 디스토피아, 정치극, SF | `세상이 망할수록 집중력이 올라갑니다` |
| 서비스신 부작용 민감형 | 서비스신/하렘 지뢰 높음 | `불필요한 자극 성분이 몰입을 방해할 수 있습니다.` | 서비스신 적은 작품, 서사 중심 | `약효보다 부작용 관리가 먼저입니다` |
| 느린전개 조기중단 위험군 | 느린 초반 지뢰, 즉효 선호 | `3화 이전 약효가 없으면 중단할 가능성이 높습니다.` | 초반 몰입 강한 작품 | `초반 10분 안에 약효가 필요합니다` |
| 고구마 회피성 과민반응 | 답답한 전개/주인공 지뢰 높음 | `답답함이 쌓이면 추천 전체에 대한 신뢰가 떨어집니다.` | 전개 빠른 작품, 명확한 성장 | `분노 유발 성분을 강하게 제한해야 합니다` |

## 8. 추천 결과를 납득 가능하게 보여주는 방식

작품은 단순 점수순으로 노출하지 않고 약 종류처럼 나눈다.

| 분류 | 기준 | 설명 |
|------|------|------|
| 즉효약 | 현재 선택한 감정/과목과 직접 맞고 초반 몰입이 빠름 | 지금 바로 보기 좋은 1순위 |
| 장기복용약 | 초반은 느리지만 후반 약효가 강함 | 장편 허용 또는 느린 전개 내성이 있을 때 |
| 응급처방 | 기분 전환, 저자극, 짧은 러닝타임 | 멘탈 회복과/개그 결핍에 적합 |
| 고위험 고효능 | 지뢰 근처 요소가 있지만 성향 적합도가 높음 | 주의사항을 붙이고 강하게 추천 |
| 금지약 | 지뢰와 강하게 충돌 | 이번 처방에서는 제외하고 이유 설명 |

작품별 설명 필수 요소:

1. 왜 이 작품이 나왔는지
2. 어떤 취향 요소와 맞는지
3. 어떤 부분은 조심해야 하는지
4. 지금 상태에서 왜 적절한지
5. 비슷하지만 제외한 작품이 있다면 왜 제외했는지

예시:

```text
왜 처방됐나요?
문진표에서 배틀뽕, 라이벌 인정 관계, 성장 서사 반응이 높게 나왔습니다.
이 작품은 초반부터 목표와 충돌이 명확해 약효가 빠르게 나타납니다.

주의사항
중반부 훈련/축적 구간에서 약효가 잠시 늦어질 수 있습니다.
느린 전개 알레르기가 심한 경우 3화까지는 보호자 없이 판단하지 마세요.
```

## 9. 결과 페이지 구조

권장 구조:

1. 처방전 헤더
   - `과몰입 클리닉 처방전`
   - `엔터테인먼트용 취향 진단 결과`
2. 환자 정보
   - 환자명: `익명의 시청자`
   - 진료 과목: `최애중독 정신과`
   - 발급일: 오늘 날짜
3. 대표 진단
   - 진단명
   - 과몰입 수치 또는 위험도
   - 한 줄 요약
4. 진단 소견
   - 3~5문장
   - 답변 근거를 자연어로 설명
5. 취향 키워드
   - `#처연캐`, `#구원서사`, `#관계성`, `#최애발생률높음`
6. 처방 작품
   - 1차 처방: 즉효약
   - 2차 처방: 장기복용약
   - 3차 처방: 고위험 고효능 또는 응급처방
7. 작품별 처방 정보
   - 효능
   - 복용법
   - 부작용
   - 맞는 태그/주의 태그
8. 금지약 / 주의약
   - 제외한 성분과 이유
9. 재처방
   - 4개 버튼
10. 공유
   - 공유 카드 생성
   - 결과 저장

## 10. 재처방 UX

MVP 재처방 버튼 4개:

| 버튼 | 조정 방향 |
|------|-----------|
| 약이 너무 셌어요 | 후유증/잔인함/비극성 가중치 낮춤, 힐링/코미디/완결작 가중치 상승 |
| 효과가 약했어요 | 카타르시스/후유증/고위험 고효능 가중치 상승, 평이한 추천 제외 |
| 최애 성분이 부족해요 | 캐릭터성/관계성/처연/천재/빌런 태그 가중치 상승 |
| 지뢰 밟았습니다 | 사용자가 고른 지뢰 태그를 하드 제외로 전환하고 대체 후보 재계산 |

1. `세계관을 더 진하게 주세요` - 설정, 정치극, SF, 디스토피아 강화

11. `설명이 너무 많아요` - 세계관 설명 많은 작품 감점

13. `스포일러 위험 낮춰주세요` - 오래된 결말 화제작/검색 위험 높은 작품 감점

15. `취향을 더 세게 찔러주세요` - 최고 점수 태그 조합을 더 극단적으로 반영

## 12. AI 활용 방향

AI에게 전체 추천을 맡기지 않는다. 추천 후보 선정은 서비스 데이터와 룰 기반 로직이 담당하고, AI는 결과 문구 작성과 태그 표현 번역을 담당한다.

### 서비스 데이터가 담당할 영역

- 작품 후보 선정
- 기존 태그 기반 유사도 판단
- 지뢰 요소 반영
- 이미 본 작품 제외
- 완결 여부, 작품 길이, 입문 난이도 고려
- 추천 목록 생성
- 금지약 후보 산출

### AI가 담당할 영역

- 사용자 답변을 취향 성향으로 해석
- 진단명 선택 또는 후보 생성
- 진단 소견 작성
- 작품별 효능 작성
- 작품별 복용법 작성
- 작품별 부작용 작성
- 금지약 / 주의약 문구 작성
- 공유 카드 문구 작성
- 기존 태그를 사용자-facing 표현으로 변환

### 안전 장치

- AI는 서비스가 제공한 작품 후보 목록 안에서만 작성한다.
- AI가 후보 외 작품명을 생성하면 결과를 폐기한다.
- 스포일러 금지.
- 실제 의료 조언처럼 보이는 문구 금지.
- 지뢰 요소를 무시한 추천 금지.
- 작품 정보가 불확실하면 단정하지 않는다.

## 13. AI 프롬프트

### 13.1 시스템 프롬프트

```text
너는 오타쿠 커뮤니티 서비스의 "과몰입 클리닉" 애니 처방전 작성자다.

목표:
사용자의 취향과 현재 기분을 바탕으로 애니 추천 결과 문구를 작성한다.
일반 추천문이 아니라 병원 진단서/처방전 콘셉트의 엔터테인먼트용 취향 진단 결과로 작성한다.

문체:
- 차분한 의사 말투를 기본으로 한다.
- 오타쿠 취향을 정확히 찌르는 위트가 있어야 한다.
- 사용자를 과하게 비하하지 않는다. "찔리지만 기분 나쁘지 않은" 수준으로 쓴다.
- "추천"보다 "처방", "시청"보다 "복용", "주의점"보다 "부작용/주의사항/금지약"을 우선 사용한다.
- 밈을 남발하지 않는다. 문장 자체의 말맛으로 웃기게 쓴다.
- 실제 질병명처럼 오해될 표현, 실제 의료 조언처럼 보이는 표현은 피한다.
- 이 결과는 엔터테인먼트용 취향 진단임을 전제로 한다.

출력 원칙:
- 작품 후보는 서비스가 제공한 목록만 사용한다.
- 후보 목록에 없는 작품을 새로 추천하지 않는다.
```

## 15. MVP 개발 순서

### 15.1 기능 구현 순서

1. **라우트와 정적 콘텐츠 MVP**
   - `/play/anime-clinic` 생성
   - 접수 화면, 진료 과목 선택, 문진표, 결과 더미 화면 구현
   - 로그인 없이 사용 가능

2. **질문/진단/태그 해석 데이터 정의**
   - 진료 과목 5개
   - 문진 질문 7개
   - 진단명 15~20개
   - 지뢰 요소 10개
   - 태그 번역 사전

3. **작품 후보 데이터 연결**
   - 기존 작품/뉴스/태그 데이터 중 애니 작품 100개 수준을 후보로 사용
   - 작품별 태그, 완결 여부, 길이, 지뢰성 태그를 추천 계산에 반영

4. **추천 스코어링 로직**
   - 문진 답변을 취향 축 점수로 변환
   - 작품 태그와 취향 축 매칭
   - 지뢰 태그는 강한 감점 또는 제외
   - 결과 3개와 금지약/주의약 후보 산출

5. **AI 결과 문구 생성**
   - 추천 후보는 서비스 로직으로 고정
   - AI는 진단 소견, 효능, 복용법, 부작용, 공유 문구만 생성
   - 후보 외 작품명 생성 방지 검증

6. **재처방 버튼 4개**
   - `약이 너무 셌어요`
   - `효과가 약했어요`
   - `최애 성분이 부족해요`
   - `지뢰 밟았습니다`
   - 버튼별 가중치 조정 후 결과 재생성

7. **공유 카드 1종**
   - 클라이언트에서 이미지 생성 또는 서버 API로 PNG 생성
   - 진단명, 요약, 처방 작품 3개, 주의사항, CTA 포함

8. **운영 검수**
   - 말맛 문구 검수
   - 지뢰 반영 테스트
   - 후보 외 작품 생성 여부 테스트
   - 스포일러 문구 검수

### 15.2 콘텐츠 제작 순서

1. 진료 과목 카피 확정
