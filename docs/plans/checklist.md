# 단계별 개발 체크리스트

이 문서는 완료/미완료 상태를 추적하기 위한 체크리스트다. 세부 기획은 각 도메인 문서를 참고하고, 여기에는 진행 상태를 명확히 남긴다.

## Phase 1. 프로젝트 기반 구축 (완료)

- [x] Next.js App Router + TypeScript + Tailwind CSS 프로젝트 생성
- [x] Zustand 기반 캐릭터 상태 관리 구조 구축
- [x] Supabase 클라이언트와 인증 기반 연결
- [x] 전역 GNB와 Live2D 렌더링 컨테이너 구성
- [x] 기본 캐릭터 프로필과 업로드 캐릭터 라이브러리 구조 구성

## Phase 2. 커뮤니티 기본 루프 구축 (진행 중)

### 2.1 게시판과 글

- [x] `boards` 테이블 기반 독립 게시판 구조
- [x] `/board/[slug]` 게시판 목록과 글쓰기 라우팅
- [x] `posts`의 `board_id`, `source_type`, `origin_post_id` 기반 하이브리드 구조
- [x] 게시판 공지, 말머리, 정렬, 검색 UI (완료)
- [x] 게시글 조회수, 댓글 수, 추천/비추천 수 집계 (`posts` 집계 컬럼 + 트리거/RPC, 목록·상세·피드 UI)
- [x] 게시글 수정, 삭제, 잠금, 숨김 상태 모델 (완료)
- [x] 게시판별 익명 허용, 미디어 허용, 글쓰기 권한 정책
