# 단계별 개발 체크리스트

이 문서는 현재 구현 상태와 앞으로의 작업 범위를 추적하는 기준 문서다. 제품 방향은 [planner-brief.md](../planner-brief.md), 모집/공유용 화면 구조는 [planner-recruitment-screen-board.md](../planner-recruitment-screen-board.md), 세부 설계는 각 도메인 문서를 기준으로 한다.

상태 기준:

- `[x]` 코드 또는 DB 기준으로 1차 구현이 확인됨
- `[ ]` 미구현, 정책 미확정, 또는 구현은 있으나 적용/검증이 더 필요함
