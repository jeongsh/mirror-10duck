# 마오 상주 캐릭터 개발 플랜

## 목표

로그인 이후 메인에 상주하는 Live2D 캐릭터를 장식이 아니라 상태 안내, 피드백, 재방문 동기, 개인화의 중심 UI로 만든다. 2차 확장 전까지는 마오를 기본 캐릭터로 고정하고, 비로그인 사용자도 체험할 수 있게 한다.

## 0차: 즉시 개발 범위

- 기본 내장 캐릭터 우선순위를 마오로 변경한다.
- 선호 캐릭터가 없는 로그인 사용자는 마오를 기본으로 본다.
- 비로그인 사용자는 마오 기본 캐릭터를 체험할 수 있다.
- 비로그인 상태에서는 캐릭터 표시 ON/OFF만 로컬 설정으로 제공한다.
- 캐릭터를 숨긴 사용자에게도 기본 토스트로 동일한 피드백을 보여줄 수 있는 fallback 레이어를 둔다.
- 캐릭터는 별도 시스템 버튼이 아니라 마오를 클릭해 열린 말풍선 메뉴에서 숨길 수 있게 한다.
- 캐릭터 숨김 상태에서는 우측 슬롯에서 다시 켤 수 있게 한다.

## 1차 확장 전까지의 운영 원칙

- 캐릭터는 알림 시스템 자체가 아니라 알림을 표현하는 채널이다.
- 캐릭터 ON: 말풍선, 표정, 모션으로 피드백을 확장한다.
- 캐릭터 OFF: 동일한 정보는 기본 토스트, 알림 목록, 배너로 제공한다.
- 비로그인 사용자에게는 개인화, 저장, 성장, 친밀도, 의상 해금 기능을 제공하지 않는다.
- 로그인은 캐릭터를 처음 보는 순간이 아니라 마오 또는 내 캐릭터가 내 계정에 저장되는 순간으로 설계한다.

## MVP 체크리스트

- [x] 마오를 기본 캐릭터로 설정
- [x] 비로그인 마오 체험 제공
- [x] 마오 클릭 말풍선 메뉴에서 캐릭터 숨김 제공
- [x] 캐릭터 숨김 상태에서 다시 켜기 UI 제공
- [x] 캐릭터 OFF 상태용 기본 토스트 레이어 추가
- [x] 비로그인 말풍선 메뉴를 체험형 액션으로 분리
- [x] 페이지별 로그인/비로그인 안내 대사 분리
- [x] 마오 기본 감정/액션 대사를 서비스 맥락형 문장으로 교체
- [ ] 주요 서비스 이벤트를 공통 피드백 버스로 정리
- [ ] 저장 성공, 오류, 알림, 복귀 메시지를 캐릭터/토스트 채널로 분기
- [ ] 표시 모드를 `기본 / 조용한 / 미니 / 숨김`으로 확장

## 2차 확장 후보

- 친밀도, 성장, 의상/포즈 해금
- 사용 패턴 기반 개인화 대사
- 시즌 이벤트와 캐릭터 상태 변화
- 사용자별 말투, 성격, 반응 빈도 설정
