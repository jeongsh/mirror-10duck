# 바이럴 진입 기능 IA

## 결론

GNB에는 바이럴 기능을 개별 탭으로 늘리지 않는다. 상위 항목은 `바이럴` 하나로 두고, 그 아래를 `정체성 만들기`, `시즌 공유`, `참여형 놀이`로 나눈다.

이 구조는 가입 전 유저에게는 가벼운 생성/테스트 경험을 주고, 가입 후 유저에게는 프로필, 오시, 게시판, 시즌 알림으로 이어지는 길을 만든다.

바이럴 기능의 개발 우선순위는 [viral-growth-priority.md](./viral-growth-priority.md)를 기준으로 한다. 현재 기준에서는 데이터 수집보다 공유성, 논쟁성, 반복 플레이, 유저 초대 동기를 우선한다.

## 현재 제품 축

- `홈`: 최근 글과 인기 채널 진입
- `채널`: 게시판 디렉터리와 게시판별 글
- `피드`: 개인/전체 피드
- `소식`: 뉴스
- `이번 분기`: 신작 라인업과 관심작
- `캘린더`: 릴리즈 일정
- `프로필`: 오시, 배지, 카드, 레벨, 관심작 설정
- `Live2D`: 전역 캐릭터와 말풍선/알림 보조 레이어

## 신규 상위 계층

### 바이럴

공유 가능한 결과물을 만드는 모든 가입 전후 기능의 상위 허브다. URL은 `/play`로 둔다.

### 정체성 만들기

- `/play/oshi-card`: 오시 프로필 카드 생성기
- `/play/otaku-type`: 오타쿠 성향 테스트
- `/play/oshi-analysis`: 최애 기반 취향분석
- `/play/timeline`: 내 덕질 연대기 생성기

이 그룹은 프로필 저장, 배지 등록, 같은 오시 유저 추천으로 이어진다.

### 시즌 공유

- `/play/season-checklist`: 분기 애니 취향표/체크리스트
이 그룹은 관심작, 방영 알림, 분기별 반복 방문으로 이어진다.

### 참여형 놀이

- `/play/tier-maker`: 티어표 빌더
- `/play/race-vote`: 레이스형 인기투표
- `/play/worldcup`: 최애/작품 월드컵
- `/play/speech-bubble`: 캐릭터 말풍선 밈 생성기
- `/play/match`: 오시 궁합/취향 매칭
- `/play/recommend`: 애니 추천 룰렛

이 그룹은 게시판, 댓글, Live2D 캐릭터성, 유저 관계망으로 이어진다.

## GNB 원칙

- 평면 탭은 최대 6개 안팎으로 유지한다.
- `신작`과 `캘린더`는 바이럴 메뉴에 넣지 않고 기존 제품 축으로 유지한다.
- 새 바이럴 기능이 MVP 이전이면 GNB 드롭다운에서는 `/play` 허브로 보낸다. 404 링크를 만들지 않는다.
- 구현 완료된 기능만 직접 URL로 연결한다.

## 추천 전환 흐름

1. 성향 테스트로 유입
2. 오시 프로필 카드 생성
3. 가입하면 카드 저장 가능
4. 같은 오시 유저/게시판 추천
5. 티어표/인기투표/월드컵으로 참여 확산
6. 게시판/피드/프로필로 재방문

## 바이럴 우선순위

1. 오시 프로필 카드 생성기
2. 오타쿠 성향 테스트
3. 최애 기반 취향분석
4. 티어표 빌더
5. 레이스형 인기투표
6. 월드컵 플랫폼
7. 덕질 연대기
8. 말풍선 밈 생성기
9. 애니 추천 룰렛
10. 분기 애니 체크리스트 고도화
