# 화면별 완료 기준

이 문서는 화면 완성도, 페이지별 완료 기준, UX 누락 점검을 할 때 참고한다. 상세 정책은 각 도메인 문서를 함께 본다.

## 홈

- 팔로우 게시판, 인기 게시글, 개념글, 최근 활동이 한 화면에서 드러난다.
- 로그인 여부에 따라 글쓰기/프로필/알림 진입이 자연스럽게 바뀐다.
- Live2D 캐릭터가 페이지를 가리지 않고 상태 반응을 보여준다.

## 게시판 목록

- 전체 게시판, 인기 게시판, 팔로우 게시판을 구분한다.
- 각 게시판의 설명, 글 수, 최근 글, 팔로우 상태를 보여준다.
- 검색 또는 필터로 원하는 게시판을 찾을 수 있다.

## 게시판 상세

- 공지, 말머리, 정렬, 검색, 글쓰기, 팔로우, 규칙 확인이 가능하다.
- 글 목록의 정보 밀도가 커뮤니티 사이트답게 충분해야 한다.
- 모바일에서도 제목, 댓글 수, 추천 수, 작성자, 시간이 읽기 쉬워야 한다.

## 글 상세

- 본문, 작성자, 지표, 댓글, 추천/비추천, 리액션, 신고, 공유, 목록 이동이 완성되어야 한다.
- 삭제/숨김/잠금 상태가 사용자와 운영자에게 다르게 보인다.
- 작성자 본인에게 수정/삭제가 보여야 한다.

## 글쓰기

- 제목, 말머리, 본문, 미디어, 스티커, 임시저장, 미리보기, 게시판 정책 검증을 제공한다.
- 업로드 실패나 작성 중 이탈 같은 실제 사용 상황을 처리한다.
- 작성 완료 후 이동 위치가 명확해야 한다.

## 프로필

- 사용자 정보, 대표 캐릭터, 작성글, 댓글, 팔로우, 스크랩, 차단 관리가 가능하다.
- 닉네임 유형과 대표 캐릭터가 커뮤니티 전반의 작성자 표시에 반영된다.

## 운영자 화면

- 신고 큐, 콘텐츠 숨김/삭제/복구, 사용자 제재, 게시판 공지/규칙 관리, 로그 확인이 가능하다.
- 운영 액션은 확인 단계와 결과 피드백을 가져야 한다.
