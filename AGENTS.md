# Project Instructions

- For Supabase schema or data changes, do not create `.sql` files by default. Apply the change directly through the Supabase MCP server unless the user explicitly asks for a SQL file or migration artifact.
- Use UTF-8 encoding for all created or modified text files.
- When running shell commands that read or write text, assume UTF-8 and avoid commands that may rewrite files using a legacy Windows code page.
