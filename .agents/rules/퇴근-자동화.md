# 퇴근 자동화 규칙

사용자가 `퇴근`이라고 요청하면 `/퇴근` 워크플로를 우선 실행한다.

실행 기준:
- `퇴근`
- `퇴근할게`
- `퇴근하자`
- `오늘은 여기까지`

동작 규칙:
1. `docs/plan.md`, `docs/plans/checklist.md`, 관련 `docs/plans/*.md`, `docs/ARCHITECTURE_OVERVIEW.md`, `docs/DB_TABLES.md`를 필요에 따라 업데이트한다.
2. 실제 변경된 문서만 스테이징하고 한국어 커밋 메시지로 커밋한다.
3. `git push`까지 수행한다.
4. 결과를 간단히 보고한다.
