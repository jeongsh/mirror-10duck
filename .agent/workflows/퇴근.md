# 퇴근

## 설명
퇴근 전 문서 마감과 git 반영을 한 번에 수행한다.

## 단계
1. 오늘 날짜 기준으로 `docs/plan.md` 하단에 "일일 마감 로그"를 갱신한다.
   - 최소 항목: 오늘 한 일, 남은 일, 내일 할 일
2. `docs/ARCHITECTURE_OVERVIEW.md` 하단에 "최근 변경 메모"를 갱신한다.
   - 오늘 변경된 구조/역할 관점 메모 1~3줄
3. `docs/DB_TABLES.md`를 갱신한다.
   - 신규 테이블/컬럼/RLS 변경 사항 반영 (변경이 없으면 확인 메모)
4. Git 명령을 순서대로 실행한다.
   - `git add docs/plan.md docs/ARCHITECTURE_OVERVIEW.md docs/DB_TABLES.md`
   - 한국어 커밋 메시지로 커밋 (예: `docs: 퇴근 전 문서 업데이트`)
   - `git push`
5. 마지막으로 아래를 짧게 보고한다.
   - 수정 파일
   - 커밋 메시지
   - 푸시 결과(브랜치/원격)

## 주의
- 위 세 문서 외 파일은 스테이징하지 않는다.
- 커밋 실패 시 원인 해결 후 새 커밋으로 진행한다.
